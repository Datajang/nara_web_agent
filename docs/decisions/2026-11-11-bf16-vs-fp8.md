# Qwen3.5-9B BF16 vs FP8 (L4, vLLM 0.19.1) — FP8 채택
- 명세 위치: §8.2 (기본 FP8, `--quantization fp8`·`--max-model-len 32768`·`--max-num-seqs 8` [미확인]), §13.2
