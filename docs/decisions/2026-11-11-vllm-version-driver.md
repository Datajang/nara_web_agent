# vLLM 버전: 드라이버 550에서는 0.19.1이 상한
- 명세 위치: §8.2 ("Qwen3.5 9B는 vLLM 0.17.0 이상")
- 질문: 이 VM(L4, 드라이버 550.54.15 = CUDA 12.4, Debian 11 glibc 2.31)에 어떤 vLLM을 설치할 수 있는가
- 방법: PyPI 메타데이터에서 vLLM 0.17~0.33의 torch 고정 버전과 휠 glibc 태그, torch의 CUDA 의존성을 조회
- 결과: 0.17.0~0.19.1은 torch 2.10(cu128) + manylinux_2_31. 0.20 이상은 torch 2.11 이상(CUDA 13.0, 드라이버 580 이상 필요)이고 0.20.x는 glibc 2.35를 요구. cu128 torch는 CUDA 12.x minor version 호환으로 드라이버 550에서 동작(v1 vLLM 0.10.2도 cu128로 운영 중이었음)
- 결정: P0-b는 vLLM 0.19.1. 0.19.1에서 Qwen3.5-9B와 §8.2 플래그 전부 동작 확인(`docs/LLM_SETUP.md`)
- 명세 수정 필요: 있음 — §8.2에 "드라이버 550 기준 vLLM 0.19.1 고정, 최신을 쓰려면 드라이버 580 이상" 추가. 드라이버 업그레이드 여부는 사용자 결정
