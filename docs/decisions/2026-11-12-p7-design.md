# P7 디자인 개편
- 명세 위치: §10.1 색상 토큰·§10.2 모서리, §13 P7
- 질문: 화면이 'AI가 만든 SaaS 템플릿'처럼 보인다(사용자 의견). 평가 배점 막대는 파란색 한 가지라 항목을 구분하기 어렵다
- 방법: frontend-design 스킬로 계획 → 검토 → 구현 → 스크린샷 비평(1280·375px). 배점 색은 dataviz 스킬의 검증된 범주 팔레트를 `validate_palette.js`로 흰 바탕에 대해 확인(인접 CVD ΔE 9.1, 일반 19.6, 3개 색은 3:1 미만 → 이름·점수 병기로 해소)
- 결정(구현):
  - 방향 '공문서': 서류철 회색 종이 `#F2F3F0`, 공문 남색 `#1E3F74`, 먹색 글자 `#16202F`, 관인 주홍 `#B3261E`. 크림색+테라코타, 밝은 파랑+알약 배지 같은 흔한 조합을 피함
  - 한 가지 상징 = 도장: 로고는 주홍 테두리 '입찰' 도장, 같은 모양을 마감 3일 이내 D-day에만 사용(`DeadlineStamp`)
  - 공고 목록은 떠 있는 카드 대신 한 장의 대장(줄마다 가는 선, 왼쪽 마감 칸, 오른쪽 한 줄 동작). 상세 머리도 같은 구조
  - 배지는 알약 → 각진 꼬리표(3px), 버튼·입력 4px, 카드 6px, 그림자는 팝오버에만. 사이드바 활성은 채운 배경 대신 왼쪽 막대
  - 배점: 항목마다 `--series-1..8` 고정 순서, 9번째부터 '기타'로 묶음. 누적 막대 조각·목록 견본·미니 막대가 같은 색
  - 첨부 목록은 아이콘 | 이름·종류 | 보기·상태 3칸(375px에서 줄이 깨지던 문제)
- 시험: 대비 테스트(토큰), DeadlineStamp·formatShortDate·배점 색·기타 묶음 테스트, vitest 153, 로컬 e2e 통과. 흔들리던 화면 이동 테스트 3개는 고정 대기 대신 `vi.waitFor`
