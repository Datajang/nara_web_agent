# 공고명 검색과 관심 공고 1억 기준 (2026-11-16)
- 명세: §6.3 SearchQuery.title, §7.3 입력, §4 users.feed_include_small, §13 P6 관심 공고 2
- 요청(사용자): 공고 검색을 키워드뿐 아니라 공고 제목으로도. 관심 공고에 1억 미만이 너무 많음 →
  기본은 1억 이상, 사용자가 원하면 설정으로 1억 미만도.

## 확인한 것
- 키워드 칩도 제목을 단어별로 찾지만(ILIKE AND), 칸 이름이 '키워드'이고 쉼표로 칩이 나뉘며 50자에서 잘림.
  최근 30일 공고 18,339건 중 쉼표 든 제목 833건, 50자 넘는 제목 735건.
- 진행 중 공고는 예산 없는 것이 0건(일반 3,085·사전규격 62)이라 1억 기준으로 빠지는 '예산 없음'은 없음.
  1억 미만은 일반 661건(21%)·사전규격 12건.

## 결정
- 공고명 칸(200자): 띄어쓰기를 지운 제목에 띄어쓰기를 지운 입력이 그대로(순서대로) 들어 있으면 맞음.
  키워드·다른 조건과 AND. URL `title=`, 최근 검색 칩에 '공고명: …'.
- 관심 공고: 기본 `budget >= 1억`, `users.feed_include_small`(0007, 기본 false)이면 제한 없음.
  화면 머리에 '1억 원 미만 공고도 보기' 체크(바로 저장·다시 불러옴), `GET /feed`가 `min_budget`을 알려 준다.
- 공고 검색의 최소 예산 기본 1억(§7.3)과 같은 기준이다.
