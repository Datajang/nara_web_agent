# 넓은 화면 개편 — 공통 껍데기 (시안 D)

- 명세 위치: §10.3 레이아웃
- 질문: 넓은 모니터에서 본문이 1200px로 묶여 양옆이 비고, 관심 공고 조건 영역이 세로로 4~5줄을 차지한다.
- 방법: 디자인 캔버스에 시안 5종(A 필터 레일·B 분할·C 표·D 마감 보드·E 대시보드)과 D를 다른 탭에 적용한 목록형 7화면을 그려 사용자가 고름
  (캔버스: claude.ai Design 아티팩트 "나라 입찰 화면 개편 시안", 비공개).
- 결정(사용자, 2026-11-18): D. 관심 공고만 마감 보드, 다른 탭은 같은 껍데기 + 내용에 맞는 목록형.
  - 본문 폭 제한 해제. 읽는 화면만 라우트 `meta.narrow`(상세·설정·양식·초대·키워드 설정·비교·404)로 1200px 유지.
  - 사이드바를 공고 / 낙찰·경쟁 / 도구로 묶음. 아이콘만(768~1023)일 때는 묶음 이름 대신 가는 선. 활성 메뉴는 연한 남색 바탕.
  - 목록 위 조건은 `UiFilterBar` 한 줄(흰 카드, 좁으면 줄바꿈, `#end`는 오른쪽 끝). 관심 공고에 먼저 적용.
  - 맞춤 추천의 적합도는 숫자만, 색칠된 막대는 쓰지 않는다(사용자 요청).
- 2단계 관심 공고 마감 보드(같은 날): 칸은 한국 시간 날짜 기준 오늘 / 1~3일 / 4~7일 / 8일 이후·미정
  (시안의 '이번 주·다음 주 이후'는 요일마다 뜻이 바뀌어 날 수로 정함, 칸 머리 색은 기존 마감 색 규칙과 같음).
  `GET /feed?due=`를 칸마다 부르고 total을 칸 건수로 씀(구간별 건수 필드는 따로 두지 않음). 기본 보드, 목록은 view=list.
- 3~7단계(같은 날, 사용자 "나머지까지 쭉"): 공고 검색 두 줄 조건 카드(접기 없앰, 정렬은 결과 머리) ·
  맞춤 추천 두 줄 조건 카드 + `RecommendList`(적합도 숫자·라벨, 추천 이유 상자) · 수주 현황 요약 숫자 띠, 투찰 결과 필터를
  조건 막대에 · 업체 검색 한 줄 막대 · 경쟁사 2xl에서 레이더|관심 경쟁사 나란히 · 어시스턴트 1400px 이상 '대화에 나온 공고' 칸 ·
  내 기록 북마크 카드에 메모 나란히(xl). 시안과 달리 낙찰 화면들은 기존 표를 살림(이미 넓은 표라 폭 해제만으로 충분).
  사이드바의 '오늘 마감' 숫자는 아직 없음(필요하면 `/feed?due=today&limit=1`의 total로 가능).
- 명세 수정 필요: §10.3, P6 관심 공고·`GET /feed` 표 반영함.
