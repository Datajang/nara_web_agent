# 입찰공고 목록 엑셀 다운로드

- 명세 위치: §7.2 관심 공고·§7.3 공고 검색·§7.4 맞춤 추천 (새 기능), API `POST /api/v1/bids/export`
- 질문: 13열(카테고리·업무·분류·공고일·공고명·공고기관·마감일·추정가격·입찰현황·공고번호·비고·공고문·URL)을
  어떤 값으로 채울지, 범위는 어디까지인지. 수집 공고는 모두 용역이다.
- 결정(사용자, 2026-11-22):
  - 카테고리=일반공고/사전규격, 업무=`srvceDivNm`(사전규격 `bsnsDivNm`), 분류=`pubPrcrmntClsfcNm`(사전규격은 빈칸)
  - 입찰현황=진행중/마감/취소, 비고=공고 종류(등록공고 생략)+변경 차수(예: 변경공고 2차)
  - 공고문=`stdNtceDocUrl` → 없으면 첫 첨부, 사전규격은 `specDocFileUrl1`. URL=상세 링크
  - 범위=지금 화면에 보이는 공고만(관심 공고 보드는 네 열 전부). 최대 500건(검색 상한)
- 구현: 엑셀은 서버(openpyxl)가 만든다 — 위 값은 원본 raw에만 있다. 화면 순서 유지, 없는 ID는 뺀다.
  문자열 셀은 문자열 형식으로 써서 `=`로 시작하는 공고명이 수식이 되지 않게 했다. 파일 이름 `YYYY-MM-DD_입찰공고 목록.xlsx`(KST).
