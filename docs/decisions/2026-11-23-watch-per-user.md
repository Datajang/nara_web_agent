# 관심 경쟁사 계정별·팀 목록, 둘러보기 검색 기록 제외, 비밀번호 확인·찾기

- 명세 위치: §15.3·§15.6(관심 경쟁사), §6.2(search-runs), §9.2(가입·재설정 화면)
- 계기: 운영 피드백(사용자, 2026-11-23)

## 관심 경쟁사
- 전: 서비스 전체가 한 목록을 공유(PK bizno). 후: 계정별(PK user_id+bizno, 마이그레이션 0012)
- 팀 목록은 따로 저장하지 않고 팀원(나 포함)의 개인 목록을 회사별로 묶어, 담은 사람 이름과 함께 보여 준다(사용자 선택)
- 기존 행은 추가한 사람의 개인 목록으로 옮기고, 추가한 사람을 모르는 행은 지웠다(사용자 선택)
- 레이더·비교 화면의 관심 여부(`watched`)는 내 목록 기준. 어시스턴트 도구의 비교는 관심 여부를 쓰지 않는다
- 0012는 PK가 바뀌어 이전 코드와 호환되지 않는다 — 롤백하면 관심 경쟁사 추가만 실패한다

## '키워드 없음' 검색 기록
- 원인: 공고 검색 탭을 열면 조건 없는 기본 검색이 돌아 실행마다 기록이 남았다(운영 30건 중 24건)
- 결정: 키워드·공고명·기관이 모두 없는 검색(둘러보기)은 내 기록·최근 검색에 보이지 않는다.
  더 보기용 스냅샷은 필요하므로 계정마다 가장 최근 한 건만 두고 새 둘러보기 때 이전 것을 지운다
- 구현: `history.repo.is_browse`·`browse_run()`, `search.service.search_bids`

## 비밀번호
- 가입·새 비밀번호 화면에 '비밀번호 확인' 칸. 다르면 서버에 보내지 않고 확인 칸에 안내(화면만, API 변경 없음)
- 비밀번호 찾기는 이미 있었다(`/forgot-password` → 메일 → `/reset-password`). 로그인 화면 맨 아래 작은
  '비밀번호를 잊었어요' 링크를 로그인 버튼 바로 아래 '비밀번호가 기억나지 않나요? 비밀번호 찾기'로 옮겼다
