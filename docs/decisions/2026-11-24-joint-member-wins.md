# 우리 수주 현황에 공동수급 구성원 낙찰 넣기 + 낙찰 수집 6년
- 명세 위치: §15.4(수집 기간), §15.6·§15.7(우리 수주 현황), P12(투찰 결과)
- 계기: 운영 피드백(사용자, 2026-11-24) — 2021년이 1건뿐(수집 시작이 5년 전 2021-11-20), 공동수급 구성원 낙찰이 안 보임
- 확인: 날짜별 G2B totalCount와 DB 건수 대조(2022~2025 표본일 차이 0~3건 = 같은 공고 재등록). 2022년이 다른 해보다
  25% 적은 것은 원본 그대로. 2025-01-02·03 0건은 G2B도 0건(차세대 나라장터 전환). 낙찰 응답에는 대표사만 있어
  우리가 구성원인 공동수급 낙찰(계약정보 corpList)은 우리 수주 현황에서 빠져 있었다
- 결정(수집): 회사 설정 수집 기간 5년 → 6년(2021년 전체). 공고도 6년(2192일) 백필 → 재분류로 낙찰률 채움
- 결정(구성원 낙찰, 사용자 선택): 우리 회사 화면에서만 건수에 넣고 금액은 지분만큼(지분 모르면 0).
  우리가 대표인 낙찰은 지금처럼 전액. 잇는 조건: 계약의 대표 사업자 = 낙찰 업체(한 공고 여러 분류 오인 방지),
  차수 ''면 모든 차수. 비교·레이더·다른 업체 화면은 대표 낙찰끼리 그대로(공정한 비교)
- 화면: 줄마다 '공동수급 구성원 · 지분 N% · 대표 ○○'와 '우리 지분 금액', 대표 공동수급은 '공동수급 대표 · 지분 N%'.
  요약 아래 '구성원 낙찰 N건 포함' 안내. 투찰 결과에서는 구성원 낙찰을 '낙찰'로, 투찰금액 대신 우리 지분 금액
- API: AwardSummaryOut.member_count, AwardOut·MyBidOut.our_role('lead'|'member')·our_share
- 한계: 계약정보 수집이 끝나야(5~6년치 약 3~4일) 과거 구성원 낙찰이 다 보인다
- 명세 수정 필요: 있음 — §15.6·§15.7(구성원 낙찰·지분 금액), §15.4(기본 수집 기간)
