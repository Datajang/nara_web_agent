# 우리 수주 현황 목록 필터 — 연도·기간·사업명
- 명세 위치: §15.6(GET /awards, 우리 투찰 결과 API), §15.7(/my-awards 화면)
- 계기: 운영 피드백(사용자, 2026-11-24) — 낙찰 목록과 투찰 결과를 연도·날짜로 거르고 특정 사업을 찾고 싶다
- 결정(API): `GET /awards`에 `q`(사업명 일부, 100자). `GET /my-bids`에 `from`·`to`·`q`.
  기간은 낙찰 등록일(KST) 기준, 끝 날 포함(기존 `/awards` 기간과 같은 규칙). `from > to`는 422.
  사업명은 공고 검색과 같은 규칙(양쪽 띄어쓰기 무시, %·_는 글자 그대로 — `search.query.title_contains`).
  `/my-bids`의 결과별 건수(전체·낙찰·탈락)도 같은 조건으로 센다
- 결정(화면): 공통 `AwardsFilter`(연도 · 시작일~종료일 · 사업명). 연도를 고르면 그해 1/1~12/31,
  날짜를 고치면 '기간 직접 지정'. 날짜는 바로, 사업명은 Enter/검색으로 적용. 거꾸로 된 기간은 안내만 하고 부르지 않는다.
  낙찰 목록은 `AwardTable filterable`일 때만(업체 검색·비교 화면은 그대로). 요약 카드·연도별 막대는 필터와 무관
- 색인: 한 업체(우리)의 낙찰만 거르므로 사업명 색인은 두지 않았다
- 명세 수정 필요: 있음 — §15.6 두 API의 쿼리 파라미터, §15.7 목록 필터 줄
