    7일 1쪽·2쪽 겹침 0(표본 1회 — 낙찰 페이지 겹침 문제(2026-11-25-awards-paging)가 있으니 하루 창 1쪽으로 받는다)
  - 과거: 2025-06-10 940행 · 2021-06-10 425행 · 2020-06-10 441행 → 6년 백필 가능(2023-06-10은 토요일이라 3행).
