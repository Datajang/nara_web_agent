# decisions/ — 확인 결과와 결정 기록

[미확인] 항목을 확인했거나 명세와 다르게 가기로 했을 때 파일 하나로 남긴다. 파일명: `YYYY-MM-DD-주제.md` (예: `2026-11-12-fp8-vs-bf16.md`).
새 세션의 Claude가 이 폴더를 읽고 같은 확인을 반복하지 않게 하려는 기록이다. 20줄 안쪽으로 쓴다.

## 템플릿

```markdown
# 제목
- 명세 위치: §x.y (원래 [미확인]이었던 항목)
- 질문: 무엇을 확인하려 했는가
- 방법: 어떤 스크립트·명령으로 확인했는가 (스크립트 경로)
- 결과: 측정값·응답 샘플 (비밀값 제외)
- 결정: 어떻게 구현하기로 했는가
- 명세 수정 필요: 있음/없음 (있으면 어느 §를 어떻게)
```

## 미리 예상되는 확인 항목 (SPEC §14와 연결)

- BF16과 FP8의 메모리·속도·품질 비교
- vLLM 옵션 `--max-model-len`, `--max-num-seqs`
- 사전규격 키와 입찰공고 키의 호출 한도
- 운영 포트·경로를 v1에 맞출지 v2 값으로 바꿀지
