# 투찰 결과 엑셀 다운로드 — 짧은 설계 (2026-11-25)

## 왜
'우리 수주 현황 > 투찰 결과'(낙찰·탈락)를 엑셀로 받아 보고·공유하고 싶다는 요청(사용자 전달, 2026-11-25).

## 무엇 (사용자 승인한 안)
- 버튼 '엑셀 다운로드'를 투찰 결과 탭 필터 줄에 둔다. **화면 조건 그대로**(결과 전체·낙찰·탈락, 기간, 사업명). 목록이 비면 누를 수 없음
- 파일 `{오늘 KST}_투찰 결과.xlsx`. 시트: 첫 시트 '요약' + 연도별 시트('2026', '2025' …, 최근 연도부터)
- 연도는 화면 필터와 같은 **낙찰 등록일(KST)** 기준 → 화면 건수 = 엑셀 건수
- 연도별 시트 14열: 개찰일 · 결과(낙찰/탈락/부적격, 낙찰은 연한 초록) · 사업명 · 수요기관 · 우리 순위 · 유효 업체 수 ·
  우리 투찰금액 · 투찰률(%) · 낙찰 업체(우리 대표 낙찰이면 '우리 회사') · 낙찰금액 · 낙찰가와 차이(우리 투찰 − 낙찰금액,
  낙찰 건은 빈칸) · 공동수급('대표 60%'/'구성원 25%') · 비고(우리 행 비고) · 공고번호(`번호-차수`, 상세 화면 링크)
- 공동수급 구성원: 투찰금액·투찰률·순위 빈칸, 낙찰 업체 = 대표사
- 요약 시트: 연도 · 투찰 · 낙찰 · 탈락 · 낙찰률(%) · 우리 낙찰 금액(지분 반영) + 아래에 조건·만든 날짜·
  '탈락은 개찰 결과를 받은 공고만 나와요(받은 공고 N건 기준)'
- 서식: 머리글 굵게·틀 고정(머리글 + 사업명 열까지)·자동 필터, 금액은 숫자(`#,##0`), 글자 칸은 수식으로 해석되지 않게 문자열

## 접근
A. **서버가 xlsx를 만든다**(채택): 입찰공고 목록 다운로드(`app/bids/export.py`, openpyxl)와 같은 방식, 화면 목록 쿼리(`awards.mybids.page`)를 그대로 써서 숫자가 어긋나지 않음.
B. 브라우저에서 만든다: 엑셀 라이브러리(수백 KB)를 프론트에 더해야 하고, 목록을 모두 다시 받아야 함 → 안 함.

## 정한 것(Claude 판단)
- API `GET /my-bids/export?result=&from=&to=&q=`(목록과 같은 검증, 시작>종료 422). 행 상한 5,000(우리 관련 공고 수백 건)
- 시트 안 순서: 개찰일 최신순(없으면 등록일) — 첫 열과 순서를 맞춘다
- 요청 제한 분당 20회(`mybids-export:{user}`). LLM·G2B 호출 없음
- 상세 링크는 `APP_ORIGIN/my-awards/bids/{번호}/{차수}/{분류}/{재입찰}`
